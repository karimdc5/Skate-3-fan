# Skate Fan 🛹

An **unofficial, fan-made skateboarding game inspired by Skate 3**, built to run in the browser and play well on **iPhone**, with full support for **Xbox and PS5 (DualSense) controllers**.

> Not affiliated with or endorsed by Electronic Arts. "Skate" is a trademark of its owner. All code and art here is original; no assets from the real game are used.

## Features

**Skating (Skate 3 style)**
- **Flick-it** trick controls on the right stick: Ollie, Nollie, Fakie and Switch versions, Kickflip, Heelflip, Double flips, Pop / FS / 360 Shove-its, Varial Kickflip, Varial Heelflip, Hardflip, Inward Heelflip, 360 Flip, Laser Flip, Impossible, Boneless, Late flips and Fingerflips
- A longer wind-up on the stick gives a higher pop
- Grinds and slides: 50-50, 5-0, Nosegrind, Smith, Crooked, Overcrook, Feeble, Boardslide, Lipslide, Noseslide, Tailslide. Kinked rails and hubbas keep the grind going
- Manuals and nose manuals, grabs (Indy, Melon, Method, Stalefish, Crail, Roast Beef, Nosegrab, Tailgrab), air spins, wallrides and wallies, reverts and powerslides
- Landings rated **Clean** or **Sketchy**. You bail when you land sideways, don't finish a flip, or are still grabbing
- **Hall of Meat**: every bail scores damage and lists broken bones, with ragdoll tumbles. You can bail on purpose
- **Get off your board** and walk around (Y / △)
- **Session markers**: set your spot and jump back to it
- Named **gaps**: 5 Stair, Funbox Gap, Halfpipe Transfer, Hill Kicker Gap, Mega Ramp Gap

**The park**
- Plaza with ledges, rails, a kinked rail, a funbox, kickers, benches, picnic tables and planters
- A 5-stair with handrail and hubba, a mini halfpipe, a bowl, a big quarter pipe, a drop-in hill and a **Mega Ramp**
- **Object Dropper**: drop kickers, quarter pipes, rails, ledges, manual pads and benches anywhere
- Local skaters cruising the park (run into them and you both slam)

**Modes and extras**
- **Game modes**: Own the Spot, S.K.A.T.E. vs the Coach, Hall of Meat and Death Race, with bronze, silver and gold medals
- **Replay Editor**: the last 20 seconds are always recorded. Scrub, slow-mo, follow / orbit / tripod / fisheye cameras, and a **photo mode** with a magazine-cover frame
- **Create-a-Skater**: regular or goofy stance, plus clothes, skin and deck colors
- Trick lines with multipliers, a saved best score and Hall of Meat record, and 31 challenges
- **Radio** with two original stations (Boom Bap FM and Punk Radio), generated in code
- Camera shake on slams and a skate cam that widens with speed

**iPhone + controllers**
- Touch controls, safe-area support for the notch, landscape layout, "Add to Home Screen" for full screen, and it works offline
- **Controller Connect tool**: pairing steps for Xbox and PS5 on iPhone, a list of detected controllers, a live tester, deadzone, stick swap, rumble test and **button remapping**

## Play it on your iPhone

The game is a static website, so GitHub Pages can host it for free:

1. On GitHub open this repo → **Settings** → **Pages**.
2. Under **Build and deployment** choose **Deploy from a branch**, pick **`main`** and **`/ (root)`**, then **Save**.
3. After about a minute your game is at `https://karimdc5.github.io/Skate-3-fan/`.
4. Open that link in **Safari** on your iPhone, tap **Share → Add to Home Screen**, and launch it from the home screen for full screen.

## Connecting a controller (iPhone)

**Xbox Wireless Controller**
1. Hold the **Xbox button** to turn it on.
2. Hold the **Pair button** (top edge) until the logo flashes fast.
3. iPhone **Settings → Bluetooth** → tap **Xbox Wireless Controller**.
4. Open the game and **press any button**.

**PS5 DualSense**
1. With the controller off, hold **Create + PS** until the light bar flashes.
2. iPhone **Settings → Bluetooth** → tap **DualSense Wireless Controller**.
3. Open the game and **press any button**.

Then tap the 🎮 button in the game to test buttons, adjust the deadzone, test rumble or remap buttons. (Safari only shows a controller after you press one of its buttons while the page is open.)

## Controls

| Action | Touch | Xbox | PS5 | Keyboard |
|---|---|---|---|---|
| Steer / spin / walk | Left thumb drag | Left stick | Left stick | A / D |
| Push (run when on foot) | PUSH | A | ✕ | W |
| Brake / powerslide | BRAKE | X | □ | S |
| Revert | REVERT | B | ○ | H |
| Get off / on board | 🚶 | Y | △ | O |
| Ollie | Tap or swipe ↑ on the right side | RS ↓ then flick ↑ | same | Space |
| Kickflip / Heelflip | Swipe ↖ / ↗ | RS ↓ then flick ↖ / ↗ | same | Q / E |
| Double flips / Impossible | – | Snap the flick super fast | same | 3 / 4 |
| Varial Kickflip / Heelflip | – | RS ↓ → ← then ↖ / ↓ → → then ↗ | same | 1 |
| Hardflip / Inward Heelflip | – | RS ↓ → → then ↖ / ↓ → ← then ↗ | same | 2 / 6 |
| Pop Shove-it / FS Shove-it | Swipe ← / → | RS ↓ then ← / → and let go | same | R |
| 360 Shove-it | – | RS ↓ → side → back ↓ and let go | same | 5 |
| 360 Flip / Laser Flip | Swipe ↙ / ↘ | RS ↓ then roll through ← / → to ↑ | same | F / X |
| Nollie tricks | (Pro flick mode) | Start the flick from RS ↑ | same | Shift + trick |
| Manual | Swipe ↓ and hold | Hold RS ↓ softly | same | – |
| Grab | GRAB (hold) | LT / RT (or LB / RB) | L2 / R2 (or L1 / R1) | Z / C |
| Boneless | Hold GRAB + tap | Hold a grab + ollie | same | Z + Space |
| Fingerflip | Swipe while grabbing | Flick while grabbing | same | – |
| Set / go to session marker | 📍 / ⟲ | D-pad ↑ / ↓ | D-pad ↑ / ↓ | G / T |
| Bail on purpose | – | D-pad ← | D-pad ← | B |
| Object Dropper | Pause menu | D-pad → | D-pad → | N |
| Replay Editor | 🎬 | View | Create | M |
| Switch camera | Settings | Click LS | L3 | V |
| Pause | ❚❚ | Menu | Options | Esc |

The left stick picks the grab (Indy, Melon, Nosegrab, Tailgrab, Stalefish, Method, Crail, Roast Beef) and the grind (forward for Nosegrind / Noseslide, back for 5-0 / Tailslide / Feeble). Every controller button can be remapped in the 🎮 screen.

In **Settings** you can switch touch tricks to **Pro flick** (the real Skate-style pull back and flick), turn on **auto-push**, flip the layout for left-handed play, pick a radio station, hide the local skaters, and choose the camera and graphics quality.

## Running it on a computer

It's plain HTML, CSS and JavaScript with no build step. Serve the folder with any static web server, for example:

```bash
npx http-server -p 8080 .
# then open http://localhost:8080
```

(Opening `index.html` straight from disk won't work, because browsers block ES modules on `file://`.)
